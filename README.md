# AI 漫剧手机版

面向 Android 与 iPhone 的独立 AI 漫剧创作应用。项目与「AI 漫剧制作大师」完全分离。

## 产品定位

以手机端为核心，提供从小说导入、内容解析、人物/场景/道具资产整理、剧本改编、分镜规划到漫剧成片导出的完整创作流程，并提供指定平台的视频发布辅助能力。

## 已确定的产品边界

- 支持 Android 手机与 Apple iPhone。
- 官网负责产品介绍、下载、账号、付费、订单、授权、版本更新与公告。
- 首次激活提供连续 48 小时（2 天）试用；试用结束后限制核心功能，付款成功后获得永久授权。
- 永久授权绑定用户账号，可在更换设备后登录恢复。
- 首批视频发布平台：抖音、红果短剧、快手。仅在平台官方接口及账号授权允许的范围内实现自动发布；其他情况提供合规的发布资料整理与手动上传辅助。
- 包含独立的 AI 视频剪辑工作台：上传已有视频，以自然语言描述剪辑目标，由 AI 分析素材并生成可编辑剪辑方案。
- 不包含未经用户明确要求的其他平台发布功能。
- 不制作桌面/手机壁纸；采用赛博朋克科技视觉方向，应用图标作为独立资源后续接入。

## 技术方向

- 手机端与官网：响应式 Web/PWA，优先复用同一套移动端界面。
- Android：官网分发 APK；后续可使用 Capacitor 等方式封装原生壳。
- iOS：首期提供可添加到主屏幕的 PWA；原生 IPA 分发需遵守 Apple 签名与分发规则。
- API：Python FastAPI。
- 数据库：开发阶段 SQLite，部署阶段 PostgreSQL。
- 授权、订单与支付状态以服务端记录为准，客户端不得自行授予永久授权。
