# 双模式 AI 工具接入

## 产品规则

AI 漫剧和独立 AI 视频剪辑统一提供两种模式：

1. **软件内置 AI 接口**：软件后端调用已配置的模型 API。当前文本、图片和语音接口通过部署环境变量配置，密钥不下发到浏览器。
2. **网页版 AI 工具**：软件展示服务商官方入口，由用户自行登录、上传和操作；完成后下载文件，再导入软件素材库。

## 网页版工作流

打开官方站点 → 用户自行登录 → 上传素材/输入提示词 → 在第三方网页生成或剪辑 → 下载结果 → 回到本软件素材库上传 → 关联到小说、分镜或剪辑项目。

当前网页目录只负责官方入口和流程指引，不使用第三方私有 API，不模拟登录，不读取第三方 Cookie，不自动点击网页，不绕过验证码。不同站点的地区可用性、账号套餐、用量和导出权限由第三方决定。

## 当前官方网页入口

文本：ChatGPT、DeepSeek、Gemini、Grok、豆包、Claude。
图片/视频：即梦 AI、可灵 AI。
视频剪辑：Runway、剪映/CapCut。

入口 URL 只用于打开官方站点，不代表已获得其 API 或自动化授权。

## 当前内置 API 配置方式

部署方配置：
- `AI_API_BASE_URL`、`AI_API_KEY`、`AI_MODEL`
- `IMAGE_API_BASE_URL`、`IMAGE_API_KEY`、`IMAGE_MODEL`
- `AUDIO_API_BASE_URL`、`AUDIO_API_KEY`、`AUDIO_MODEL`

AI 工具中心会显示各类服务是否已配置，但不会返回密钥。

## 后续必须完成

- 用户个人 AI 服务商配置页面与加密凭据存储（按账号隔离，密钥写入后不再回显）。
- 供应商预设、模型列表/连通性测试、费用风险提示和调用记录。
- 网页版任务记录、下载文件导入助手和素材自动关联建议。
- 视觉模型视频理解、ASR/镜头分析和视频剪辑计划适配器；不得把仅打开网页称为自动集成。
