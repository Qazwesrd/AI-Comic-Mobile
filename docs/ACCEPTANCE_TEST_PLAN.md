# 明日项目验收清单

> 本清单用于逐项验收 AI 漫剧大师手机 App、官网和后端。代码通过自动化检查，不等于已完成真实账号、短信、付款、云端部署和真机验收。

## 一、验收前准备

- [ ] 确认本次验收使用的 GitHub 提交 SHA 与 APK 构建 SHA 一致。
- [ ] 确认 PR #33 已通过 Quality Checks。
- [ ] 确认 Android Debug APK 已构建成功并下载。
- [ ] 确认测试后端已经部署到本次验收的代码版本；不要用旧生产 API 测试新版本 APK。
- [ ] 准备一个测试账号、可用邮箱、TXT 小说样本和可用的文本/图片 AI 服务配置。
- [ ] 真正的短信、支付、邮件 OAuth 生产配置未完成时，相关验收项标记为“待外部配置”，不要用假凭据代替。

## 二、账号与授权

- [ ] 注册、登录、退出、重新登录。
- [ ] 邮箱验证码申请、错误验证码、过期验证码、重复使用验证码和速率限制。
- [ ] 48 小时试用激活，检查剩余时间显示与服务端授权状态。
- [ ] 试用到期后，创作/AI生成/上传/剪辑/渲染接口被服务端阻止。
- [ ] 试用到期后，仍可登录、查看已有项目、读取素材、导出项目和访问订单/设备管理。
- [ ] 永久授权支付完成后，由服务端核验并解锁；未经核验不得显示正式版下载。
- [ ] 中国大陆手机号注册：需配置阿里云 PNVS 生产凭据后测试。
- [ ] 真实付款回调：需配置真实商户参数、Webhook 密钥和真实收款方式后测试。

## 三、小说到漫剧主流程

- [ ] 创建项目、切换已有项目。
- [ ] 导入 UTF-8 TXT 和 GB18030 TXT；验证章节标题拆分。
- [ ] 重新打开项目，确认原有小说列表和章节进度仍在。
- [ ] 分批解析章节；检查摘要、人物、场景、道具、关键事件、人物关系、时间线和连续性提示。
- [ ] 审核人物/场景/道具；未审核素材不得触发图片生成。
- [ ] 已审核素材生成视觉参考图；检查图片预览、下载和素材库关联。
- [ ] 生成剧本和分镜；退出后重新打开，检查历史成果仍可查看。
- [ ] 检查手机横屏分镜内容、人物设定一致性和剧情主线保留情况。

## 四、素材与视频

- [ ] 多文件上传、分片上传、文件类型校验、项目关联、素材审核、下载和删除。
- [ ] Android 系统分享文件到素材库。
- [ ] 独立视频剪辑：创建项目、添加视频、提取关键帧、生成 AI 剪辑建议。
- [ ] 修改片段起止时间、时间线位置、转场和字幕，保存后重新打开。
- [ ] 配置 FFmpeg 后导出 MP4；检查视频可播放、音轨/字幕和下载。
- [ ] 分镜静帧合成：选择图片顺序、时长、画幅和可选音频，创建渲染任务并下载结果。

## 五、手机体验

- [ ] Android 手机竖屏显示正常，底部五项导航可用。
- [ ] 项目页、素材页、AI工具页、账号页的表单和按钮不会被系统安全区域遮挡。
- [ ] 工作台显示最近项目，点击后直接打开对应项目。
- [ ] 从小说列表重新进入，能继续之前的解析、审核和剧本分镜步骤。
- [ ] 网络短暂中断时，页面有明确错误提示，不丢失已经保存的数据。

## 六、尚待外部条件

- 阿里云 PNVS：用户需提供生产 AccessKey/授权配置并完成真实手机号验证。
- Gmail OAuth：需配置生产 OAuth Client、授权域名和回调地址。
- 微信支付：需提供真实收款码/商户配置并完成回调联调；当前不放置假二维码。
- Android 正式发布：需提供签名密钥并完成正式签名构建；CI Debug APK 仅用于测试。
- iOS 发布：需 Apple 开发者账号、签名证书、描述文件和构建环境。
- 云端上线：必须把验收分支部署到测试/生产后端与官网；PR 未合并时，main 生产环境不会自动包含本分支代码。
