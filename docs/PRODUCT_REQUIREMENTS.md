# 产品需求说明

## 1. 产品目标
打造面向手机用户的独立 AI 漫剧创作工具，覆盖从小说/文本到漫剧成片的创作链路，并提供指定平台的视频发布能力。产品独立于「AI 漫剧制作大师」，不共享代码仓库、部署环境或用户数据。

## 2. 平台与交付
- Android：官网提供 APK 下载、版本说明和更新提示。
- iPhone：首期提供响应式 PWA，可通过 Safari 添加到主屏幕；后续如需原生 IPA，按 Apple 签名与分发规则实施。
- 官网：产品介绍、注册登录、购买、订单查询、授权管理、版本下载、维护公告和管理后台。
- 桌面浏览器可用于官网管理和创作辅助，但本产品优先按手机屏幕设计。

## 3. 核心创作流程
1. 创建项目并导入小说/文本。
2. AI 解析章节、人物、关系、场景、道具、事件和时间线。
3. 用户审核、修改并确认识别结果。
4. 生成角色设定、场景与道具视觉资产，支持统一 ID 和资产复用。
5. AI 根据原文生成保留主线含义的漫剧剧本。
6. 自动规划分集与分镜，允许用户编辑、合并、拆分和调整顺序。
7. 生成分镜画面、配音/字幕等漫剧素材。
8. 合成并导出漫剧视频及静态分镜成果。
9. 可进入发布中心，选择抖音、红果短剧或快手进行发布准备。

## 4. 视觉方向
- 赛博朋克科技风：深黑底色、电光蓝、霓虹紫，少量洋红点缀。
- 图标采用高对比金属质感与霓虹科技元素。
- 不制作桌面壁纸、手机壁纸或软件背景壁纸；界面背景仅使用轻量科技纹理/动效，优先保证手机性能和可读性。

## 5. 发布中心
首批仅包含：
- 抖音
- 红果短剧
- 快手

功能包括平台选择、账号授权状态、发布资料预览、标题/简介/封面/视频文件准备、发布任务状态、失败原因和历史记录。只有平台提供可用的官方开放接口且获得必要授权时才启用自动发布；否则提供合规的手动上传引导。不得通过模拟登录、抓取私有接口或绕过平台风控实现发布。

## 6. 明确不做的功能
- 不提供 AI 视频剪辑、上传已有视频后按文字指令自动剪辑等功能。
- 不提供未经产品负责人确认的其他平台发布入口。
- 不把旧项目的管理后台式工作流直接照搬到手机端。

## 7. 商业模式与授权
- 首次激活开始连续 72 小时免费试用。
- 试用结束后限制核心创作功能，保留登录、购买、订单/授权查询和数据导出/恢复等必要入口。
- 一次性付费获得永久使用授权。
- 授权绑定用户账号，允许在更换手机后登录恢复；设备数量、并发登录和异常转移规则由服务端策略控制。
- 付款必须由服务端验证支付渠道真实回调/订单状态后授予授权。

## 8. 用户数据与隐私
- 项目内容、上传文件和生成资产按用户隔离。
- API 密钥及支付凭据不得返回客户端或写入日志。
- 支持删除账号/数据请求和必要的数据导出。
- 大文件采用分片上传、断点续传和明确的容量提示。
